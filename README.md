# Restaurant Order Calculator

A simple web-based restaurant order calculator built with HTML, CSS, and JavaScript. Customers can select items from the menu, choose an order type, and place their order.

## Features

- **Menu Selection** - Choose from 5 items: Chicken Burger, Veg Burger, Chicken Pizza, Chicken Biryani, and French Fries
- **Quantity Control** - Increase or decrease item quantities with +/- buttons
- **Order Types** - Supports Dine In, Takeaway, and Delivery (with Rs. 100 delivery charge)
- **Customer Info** - Collects name, phone number, and address (for delivery)
- **Live Order Summary** - Real-time subtotal and grand total calculation
- **Order Confirmation** - Displays a detailed confirmation after placing an order

## How to Use

1. Open `index.html` in your browser
2. Select items and adjust quantities using the +/- buttons
3. Choose your order type (Dine In, Takeaway, or Delivery)
4. Enter your name and phone number (address required for delivery)
5. Review the order summary
6. Click **PLACE ORDER** to confirm
